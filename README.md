# 坦克大战 Tank Battle 🎮

一个纯 HTML + Canvas + JavaScript 实现的经典坦克大战小游戏，无需任何依赖，双击 `index.html` 即可在浏览器中游玩。

## 玩法

| 按键 | 功能 |
|------|------|
| `↑` `↓` `←` `→` | 移动坦克 |
| `空格` | 射击 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |

## 游戏特性

- 🎯 经典 Battle City 风格：砖墙（可摧毁）、钢墙（不可摧毁）、水面（可穿越子弹）
- 🤖 敌方坦克 AI：随机巡逻 + 追踪玩家
- 🗺️ 5 个关卡，难度递增（敌人数量与同屏上限递增），地图循环使用
- 💥 爆炸粒子效果、子弹互撞抵消
- 📊 HUD 显示得分 / 关卡 / 生命 / 剩余敌人

## 运行

直接用浏览器打开 `index.html` 即可，或启动一个本地服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 技术栈

- HTML5 Canvas 渲染
- 原生 JavaScript（零依赖，单文件）
